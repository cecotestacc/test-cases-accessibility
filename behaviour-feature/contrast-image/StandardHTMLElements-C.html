Elements with errors

Issues
  • ERROR #e0e0e0 text on a gradient overlay that fades to near-transparent at the bottom. The effective background behind the lower glyph pixels approaches white (#f9f9f9 equivalent), making the contrast ratio approximately 1.4:1 — well below 4.5:1. A static checker cannot measure this because the backdrop changes across the element height.

Auto-play video would appear behind this text layer. The overlay is too light at the bottom to provide adequate contrast for the text placed here.
