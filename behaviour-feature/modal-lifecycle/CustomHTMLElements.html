Modal Lifecycle – Custom Elements

Violation: broken modal (focus not trapped, background not inert, Escape ignored)

Correct: full lifecycle (focus in → trapped → inert background → Escape → focus returns)

Broken Modal

Focus is not trapped here. Tab will leave this dialog. The page behind is not inert. Escape does nothing.

Accessible Modal

This dialog correctly:

  • Moves focus inside on open
  • Traps Tab and Shift+Tab within the panel
  • Marks the rest of the page inert
  • Closes on Escape
  • Returns focus to the trigger on close
