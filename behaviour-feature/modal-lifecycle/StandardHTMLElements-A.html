Issues
  • ERROR focus-in Opening the dialog does not move keyboard focus inside it — focus stays on the trigger button in the page. The rule's "focus moves in" assertion fails.
  • ERROR tab-contained No Tab/Shift+Tab wrapping is implemented — Tab walks freely out of the modal into the page behind. The rule's "Tab stays contained" assertion fails.
  • ERROR aria-modal The overlay div has no role="dialog" and no aria-modal="true" — background content is not removed from the accessibility tree. The rule's tree-isolation check fails.
  • ERROR escape No keydown Escape handler is present — pressing Escape does nothing. The rule's "Escape closes dialog" assertion fails.
  • ERROR focus-return The close button does display:none on the overlay but never returns focus to the trigger. The rule's "focus returns to opener" assertion fails.
