W3C technique
F102: Failure due to content disappearing when viewport is resized to 320 CSS pixels
Elements with errors
#wrapper (900px) · .main-col (620px) · .sidebar (240px)
Issues
  • ERROR #wrapper is width:900px — already wider than the 320 CSS-pixel viewport the rule uses. The rule finds this element as the outermost node whose scrollWidth exceeds its clientWidth and reports it.
  • ERROR The two-column flex layout uses hard pixel widths (620px + 240px). Neither column collapses at 320px — they overflow the viewport horizontally.

Fixed 900px wrapper

Main content (620px fixed)

This column cannot shrink below 620 CSS pixels. At a 320px viewport a horizontal scrollbar appears and users must scroll sideways to read — a violation of SC 1.4.10.
