WCAG criteria
2.4.3 Focus Order — A
Elements with errors
<form-row> inputs · <action-bar> / <action-button>
Issues
  • ERROR Input fields carry tabindex 3 / 1 / 2 — tab sequence is Last Name → Email → First Name, which is the reverse of both DOM order and the visual left-to-right layout.
  • ERROR Action buttons carry tabindex 5 (Cancel) / 4 (Submit) — Submit (visually on the right) receives focus before Cancel (visually on the left), contradicting visual reading order.
