Case #11 hover-focus-content
WCAG criteria
1.4.13 Content on Hover or Focus — AA  ·  2.1.1 Keyboard — A
Elements with errors
<tooltip-trigger> · <hover-popover>
Issues
  • ERROR 1.4.13 <tooltip-trigger> popup has pointer-events:none — the user cannot move the pointer from the trigger into the tooltip; moving away collapses it immediately (fails "hoverable" requirement).
  • ERROR 1.4.13 <tooltip-trigger> has no Escape key handler — no mechanism to dismiss the tooltip without moving the pointer or losing focus (fails "dismissible" requirement).
  • ERROR 2.1.1 <hover-popover> opens only via CSS :hover — keyboard focus on the trigger never reveals the menu; Edit/Duplicate/Delete are unreachable by keyboard.
  • PASS <dismissible-tooltip>: pointer can enter the popup, Escape dismisses without moving focus, popup persists while pointer is inside.
