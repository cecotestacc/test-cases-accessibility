Elements with errors
#trap-section (standard HTML form with Tab interception script)
Issues
  • ERROR The keydown handler on #trap-section intercepts Tab and Shift+Tab and cycles focus among its own children — keyboard focus can never leave the section via Tab.
  • ERROR No Escape-key release, no arrow-key exit, and no documented keyboard shortcut exists to move focus out of the section. The rule's "Tab through page" simulation will detect focus cycling within this set of controls indefinitely.
  • PASS #safe-section: no Tab interception — the browser's native focus order applies and Tab leaves the section normally.
