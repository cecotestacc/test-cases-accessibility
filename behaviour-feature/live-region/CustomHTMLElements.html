Issues
  • ERROR A <notification-toast> is created with textContent already set, then inserted into the DOM — screen readers observe a new node but the text was never a mutation inside an established live region, so the announcement is missed.
  • ERROR B <update-feed>: aria-live attribute is set and content is appended in the same synchronous tick — the region has not had time to be registered with the AT before its content changes.
  • PASS #good-region exists in the DOM at parse time with aria-live="assertive"; content is only injected later on button click — AT reliably announces the update.
