Case #04 forced-colors W3C G209 — Example C
WCAG criteria
1.4.11 Non-text Contrast — AA
W3C technique
G209: Provide sufficient contrast at the boundaries of adjoining colors (shown as failure in Windows High Contrast mode)
Elements with errors
div.gradient-border-card
Issues
  • ERROR The visible border is implemented as a CSS gradient in the border-box background layer with border: 3px solid transparent. In forced-colors mode the browser replaces the background gradient with Canvas — the "border" becomes the same colour as the card interior and the page background, making the card boundary invisible.

Forced Colors — Gradient Border Card (border vanishes in High Contrast)

Enable Windows High Contrast mode or DevTools emulation (forced-colors: active) to see this failure.

This card's boundary relies entirely on a CSS gradient border. In Windows High Contrast mode that boundary disappears completely.
