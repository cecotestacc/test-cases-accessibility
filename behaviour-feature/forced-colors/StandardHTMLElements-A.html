Case #02 forced-colors W3C G209 — Example A
WCAG criteria
1.4.11 Non-text Contrast — AA
W3C technique
G209: Provide sufficient contrast at the boundaries of adjoining colors (shown as failure in Windows High Contrast mode)
Elements with errors
span.icon-mask
Issues
  • ERROR The icon is drawn using an SVG alpha mask applied to background-color:#e11d48. In forced-colors mode the browser replaces background-color with the Canvas system colour — the icon shape becomes invisible against the identical page background (contrast ratio ≈ 1:1). The rule re-renders under forced-colors:active and measures each graphic against its surroundings.

Forced Colors — CSS Mask Icon (disappears in High Contrast)

Enable Windows High Contrast mode or DevTools emulation (forced-colors: active) to see this failure.
