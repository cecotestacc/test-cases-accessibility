Case #09 forced-colors
WCAG criteria
1.4.11 Non-text Contrast — AA
Elements with errors
<css-icon> · <progress-bar> · <shadow-button>
Issues
  • ERROR <css-icon> uses mask-image + background-color — in forced-colors mode the background is replaced by a system colour; the icon silhouette becomes indistinguishable from the page.
  • ERROR <progress-bar> uses a CSS gradient for its fill — forced-colors strips all gradients; filled and unfilled portions become indistinguishable.
  • ERROR <shadow-button> has border:none; its only visible boundary is box-shadow — forced-colors removes box-shadow entirely, making the button boundary invisible.
  • PASS <svg-icon-button> uses fill:currentColor and a real border property — both survive forced-colors remapping.
