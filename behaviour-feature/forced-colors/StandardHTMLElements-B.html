Case #03 forced-colors W3C G209 — Example B
WCAG criteria
1.4.11 Non-text Contrast — AA
W3C technique
G209: Provide sufficient contrast at the boundaries of adjoining colors (shown as failure in Windows High Contrast mode)
Elements with errors
button.shadow-button
Issues
  • ERROR The button has border:none — its only visible boundary is box-shadow: 0 0 0 2px #6d28d9. In forced-colors mode box-shadow is suppressed; the button background (#f5f3ff) becomes the system Canvas colour, identical to the page background — the button boundary completely disappears.

Forced Colors — Box-Shadow-Only Button Boundary (disappears in High Contrast)

Enable Windows High Contrast mode or DevTools emulation (forced-colors: active) to see this failure.
