Case #02 accessible-name W3C F68 — Example A
WCAG criteria
4.1.2 Name, Role, Value — A  ·  2.5.3 Label in Name — A
W3C technique
F68: Failure of 4.1.2 — the user interface component does not have a programmatically determined name
Elements with errors
#firstname · #lastname · #pet-dog · #pet-cat
Issues
  • ERROR "First name:" and "Last name:" are bare text nodes — not <label> elements. Chrome's accessible-name computation finds no programmatic association for either text input; the computed name is empty.
  • ERROR "I have a dog" and "I have a cat" are inline text nodes adjacent to the checkboxes — not wrapped in <label> or referenced via aria-labelledby. Both checkboxes have an empty accessible name.
