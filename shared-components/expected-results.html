Calculation rules

Component threshold: appears if at least one (selector + rule_id) fires on 2+ pages.

Sub-issue threshold: sub-issues with <2 pages are hidden when a sibling has 2+ pages.

Share% rounding: math.floor(issues / 761 × 100 + 0.5) — round-half-up, NOT Python's round().

By-severity breakdown (numbers before "N issue types"): union of pages per severity group, Critical→High→Medium→Low.

Location: if selector contains ' > ' → 'in [everything before last >]'; else → 'at the top of the document'; 'html' → 'no single element to point at'.

Issue type name: axe-core rules: use howToFix JSON field. Behavioral rules (focus-obscured, reflow, modal-lifecycle, etc.): portal uses a short hardcoded label not in the JSON export.
