Case #18 shared-components / product-jackets
WCAG criteria
1.3.1 Info and Relationships — A | 1.4.3 Contrast (Minimum) — AA | 1.4.4 Resize Text — AA | 1.4.12 Text Spacing — AA | 2.4.3 Focus Order — A | 2.4.6 Headings and Labels — AA | 2.4.7 Focus Visible — AA | 2.4.11 Focus Not Obscured — AA | 4.1.2 Name, Role, Value — A | 4.1.3 Status Messages — AA
Elements with errors
<meta name="viewport">, nav.site-nav (no aria-label), #promo-bar (height clipped), .cookie-btn (low contrast), .hero-section h2 & p (gradient contrast), #toast-region (content pre-populated on load), .modal-close (no focus indicator), h3.section-title (skips h2), .ghost-cta (no focus indicator), nav.footer-nav (no aria-label), closeModal() (no focus restoration)
Issues
  • ERROR 1.4.4 meta viewport — user-scalable=no and maximum-scale=1.0 prevent users from zooming the page, violating resize-text requirements.
  • ERROR 4.1.2 nav.site-nav — landmark with no aria-label; a second unlabelled <nav> in the footer makes both indistinguishable to AT users.
  • ERROR 1.4.12 #promo-bar — fixed height:40px with overflow:hidden clips the second promo line when text-spacing overrides (line-height ≥1.5) are applied.
  • ERROR 1.4.3 .cookie-btn — white text on #93c5fd (light blue) yields a contrast ratio of approximately 2.2:1, far below the 4.5:1 minimum.
  • ERROR 1.4.3 .hero-section — white and near-white text rendered over a vivid three-stop gradient; contrast falls below 4.5:1 at the lightest gradient stop.
  • ERROR 4.1.3 #toast-region — live region contains content already present in the DOM at page load; assistive technologies announce live-region updates, not initial content, so the message is never read.
  • ERROR 2.4.7 .modal-close — outline:none; box-shadow:none on :focus and :focus-visible removes the focus indicator with no visible replacement.
  • ERROR 4.1.2 #product-modal — closeModal() removes the .open class without returning focus to the triggering element (#qv-trigger), breaking the modal lifecycle.
  • ERROR 2.4.6 h3.section-title — heading level jumps from h1 directly to h3 with no intervening h2, breaking the document outline.
  • ERROR 2.4.7 .ghost-cta — outline:none; box-shadow:none on :focus and :focus-visible removes the focus indicator with no visible replacement.
  • ERROR 4.1.2 nav.footer-nav — second unlabelled <nav> landmark; AT users cannot distinguish it from the site navigation.
