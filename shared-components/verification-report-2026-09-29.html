Portal Threshold Behaviour

How the portal threshold works

The QualiBooth portal groups violations by selector (the CSS target of the failing element). Each selector can have multiple sub-issues, each being a unique (rule_id, impact) pair.

The portal applies a threshold filter per selector:

  • Sub-issues found on 2 or more pages are SHOWN — they appear as component violations.
  • Sub-issues found on only 1 page are HIDDEN — suppressed as noise — but only when at least one other sub-issue for that same selector has 2+ pages.
  • If no sub-issue for a selector reaches 2 pages, all sub-issues are shown regardless (the component is never left empty).

In this report, hidden sub-issues are still listed in the Sub-issues column but are visually dimmed and marked HIDDEN 1pg. The Issues and Share% columns count only shown sub-issues, matching portal behaviour.
